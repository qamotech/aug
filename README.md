# AI Universe Guide (AUG)

An interactive field guide to AI model families, their strengths and trade-offs, ways to use AI, and local inference.

**Live site:** <https://qamotech.github.io/aug/>

## Explore

- Search and filter the model cards by specialty.
- Save favorite model families on this device.
- Compare two or three model families side by side.
- Switch between technical and beginner-friendly explanations.
- Explore deployment approaches, a prompt arena, hardware and VRAM tools, and an AI matchmaker.
- Choose light or dark appearance; reduced-motion preferences are respected.

Favorites and appearance preferences are stored in the browser when storage is available. The guide has no application backend; model descriptions are reference material and should be checked against current provider documentation before making purchasing or deployment decisions.

## Run locally

Open [`index.html`](./index.html) in a modern browser. No build step or package installation is required.
